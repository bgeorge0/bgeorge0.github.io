# Dosimetry Lab

An independent educational site for Therapeutic Radiographers learning about objective functions, inverse planning and adaptive plan review.

- [Home page and activity index](index.html)
- [Adaptive plan review simulator](plan-review-simulator.html)
- 5 clinical activities, 11 advanced activities, 6 branching workflow exercises, and 2 standalone quizzes.

The site is static; open `index.html` via GitHub Pages or serve the repository locally. Shared styles and plotting helpers live in `assets/`. `dosimetry-lab.html` preserves old links by redirecting known fragment identifiers to the new standalone pages.

All examples use fictional anatomy and simplified dose models. Not for clinical planning, approval or credentialling.

The workflow exercises use predefined, fictional prescription-statistics snapshots. The first three are adapted from a teaching presentation; the remaining cases are original examples. They do not perform dose calculation or clinical approval.
